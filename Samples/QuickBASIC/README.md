# QuickBASIC 4.5 example programs

The programs of `EXAMPLES.ZIP`, the examples that come with Microsoft QuickBASIC 4.5.  The four that MS-DOS also ships (`GORILLA`, `MONEY`,
`NIBBLES` and `REMLINE`) are in the folder above.  They are as they were distributed, with their DOS line endings.

The converter tests convert every program here without notes and compile the result.

| Program | Notes |
|---|---|
| BALLPSET, BALLXOR | Viewports and `GET`/`PUT` animation |
| BAR | Bar graph (a `TYPE` and arrays passed to procedures) |
| CAL | Calendar (`DEFINT`, a `TYPE` array, `DATA`) |
| CHECK | Checkbook balance |
| COLORS | Screen colors |
| CRLF | Makes a `.BAK` backup of a file |
| CUBE | `DRAW` macro string |
| EDPAT | Pattern editor (`DrawPattern`, `EditPattern`) |
| ENTAB | Replaces runs of spaces in a file with tabs |
| FILERR | `ON ERROR` and file errors |
| FLPT | Shows how a real value is stored in memory |
| INDEX | Random-file records with an index |
| MANDEL | Mandelbrot set (`SCREEN` 8 or 1, `ON ERROR`) |
| PALETTE | `PALETTE` changes |
| PLOTTER | Drawing with the numeric keypad |
| QLBDUMP | Names of the procedures in a Quick library |
| SEARCH | Searches a file for a pattern |
| SINEWAVE | Sine wave in a window |
| STRTONUM | String to number |
| TERMINAL | Terminal program (serial port) |
| TOKEN | A BASIC version of the C `strtok` function |
| WHEREIS | Searches the directories for a file |
