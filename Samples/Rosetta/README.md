# Rosetta Code samples

QBasic programs taken from [Rosetta Code](https://rosettacode.org) (the pages of the tasks, in the BASIC / QBasic sections), used to test
the converter on programs that other people wrote.  Each `NAME.BAS` is a program as it appears on its task page; a `NAME.OUT` next to it
is the output the page shows for it.  Rosetta Code text is available under the
[GNU Free Documentation License 1.2](https://www.gnu.org/licenses/old-licenses/fdl-1.2.html); the title of each task below is the page it came
from (rosettacode.org/wiki/TITLE).

The converter tests convert every program here and compile the result.  Programs that the converter does not handle yet are not kept here.
